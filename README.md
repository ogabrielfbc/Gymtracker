# 🏋️ GymTracker

O **GymTracker** é um projeto desenvolvido em Python com o objetivo de criar uma aplicação para gerenciamento de treinos e acompanhamento da evolução dos usuários.

Atualmente, o projeto está em desenvolvimento e novas funcionalidades serão adicionadas conforme sua evolução.

## 🛠️ Tecnologia utilizada

- Python

## 🎯 Objetivo

Desenvolver uma aplicação que permita organizar treinos, registrar atividades físicas e acompanhar o progresso dos usuários de maneira simples e intuitiva.

## 🚀 Planos para o projeto

Algumas funcionalidades que pretendo implementar:

- Interface gráfica moderna.
- Sistema de cadastro e login.
- Gerenciamento de treinos e exercícios.
- Agenda de atividades.
- Histórico de treinos.
- Gráficos de evolução.
- Banco de dados para armazenar informações.
- Painel administrativo.
